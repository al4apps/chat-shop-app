# chat-list Specification Delta

## MODIFIED Requirements

### Requirement: Содержимое элемента
Элемент списка SHALL показывать номер заказа в заголовке, описание заказа в подзаголовке, бейдж статуса заказа либо диалога, сумму текущего заказа при наличии и метку времени последней активности.

#### Scenario: Заказ с описанием
- **WHEN** у диалога есть номер заказа и описание
- **THEN** заголовком является «Заказ №N»
- **AND** подзаголовком является описание заказа
- **AND** показываются бейдж статуса и сумма

#### Scenario: Заказ без описания
- **WHEN** описание заказа пустое
- **THEN** заголовком является «Заказ №N»
- **AND** подзаголовок не показывается
- **AND** бейдж статуса остаётся видимым

#### Scenario: Заказа ещё нет
- **WHEN** у диалога нет заказа
- **THEN** заголовком является «Заказ №N» или описание диалога
- **AND** показывается бейдж статуса диалога
- **AND** сумма не показывается

#### Scenario: Статус в подзаголовке
- **WHEN** у диалога есть статус заказа
- **THEN** статус заказа показывается бейджем в элементе списка
- **AND** при отсутствии статуса заказа показывается бейдж статуса диалога

### Requirement: Порядковый номер
Система SHALL использовать `orderNo` из проекции заказа; если `orderNo` равен нулю, номер SHALL определяться по порядку создания диалогов, чтобы оставаться стабильным при сортировке по активности.

#### Scenario: Сервер вернул номер
- **WHEN** у диалога есть `orderNo > 0`
- **THEN** в списке и шапке диалога показывается этот номер

#### Scenario: Сортировка изменилась
- **WHEN** новый диалог становится первым по последней активности
- **THEN** номера уже существующих заказов не меняются

#### Scenario: Номер отсутствует
- **WHEN** `orderNo` равен нулю
- **THEN** номер определяется по порядку создания диалогов
